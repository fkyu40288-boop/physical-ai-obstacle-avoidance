# Physical AI 応用1 自由課題

## LiDARを用いた障害物回避ロボット

### 1. 概要
ROS 2とGazebo Simを用いて、LiDARの距離情報に基づいて障害物を検知し、回避する移動ロボットのシミュレーションを作成しました。

### 2. 使用技術
- ROS 2
- Gazebo Sim
- Python
- LiDAR（LaserScan）
- Odometry

### 3. 主な機能
- LiDARによる周囲の距離情報の取得
- 前方の障害物に応じた回避動作
- 障害物通過後に元の走行レーンへ戻る制御
- 条件に応じた停止処理

### 4. 実装方法
Pythonプログラムでセンサ情報を処理し、状態遷移と移動目標に基づいて速度指令を出力します。

現時点では、ルールベースの反応型障害物回避制御を実装しています。機械学習モデルを使用したものではありません。

### 5. ファイル
- `obstacle_ai.py`：障害物回避の制御プログラム
- `world.sdf`：Gazeboのシミュレーション環境
